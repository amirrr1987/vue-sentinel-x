# @vue-sentinel-x/core

Intelligence Engine, diagnostic rules, JSON/HTML reports, and shared configuration.

```bash
npm install @vue-sentinel-x/core
```

```ts
import {
  resolveConfig,
  intelligenceEngine,
  buildIntelligenceContext,
} from "@vue-sentinel-x/core";

// Browser-safe (no Node fs):
import { intelligenceEngine } from "@vue-sentinel-x/core/browser";
```
